# Actual Format Notes

This folder is reserved for future stable format designs.

The documents under `actual/docs/` are not the formats currently emitted by the repository tools. For the active implemented render-pack format, use `../docs/osmrpack_format.md` (`OSMRPK02`) with the top-level `pbf-to-rpack`, `rpack-info`, and `rpack-render` binaries.

For the active implemented route-pack format, use `../docs/OSMRTE01.md` with the top-level `pbf-to-rte`, `rte-info`, and `rte-route` binaries.
